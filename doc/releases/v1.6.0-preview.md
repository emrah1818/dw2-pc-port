## Neu gegenüber v1.5.0-preview2
- **Digimon-Status (Modern):** Die 3D-Vorschau ist größer und an ihr Fenster angepasst. Pro Digimon wird die Größe so gewählt, dass das Modell bei jeder Drehung im Fenster bleibt: Agumon 1,8×, Betamon 1,6×. Große Digimon wie Greymon bleiben so groß wie auf der PS1, weil sie das Fenster schon füllen.
- **Reiter Status / Techniken:** Beide Seiten (mit ◎ wechseln) haben eine Reiterleiste. Die aktive Seite ist hell, die andere gedimmt mit ihrem Tastenhinweis. Die Beschriftung kommt aus den Spieltexten.
- **Attackenliste:** Neben jeder Technik stehen ihre MP-Kosten, zum Beispiel „12 MP“. Beschreibung und MP-Verbrauch stehen weiterhin im Infofenster.
- **Ruckler im Modern-Fensterdesign behoben:** Das Panel-Design wird pro Fensterstück nur noch einmal berechnet, nicht bei jedem Farbwechsel neu. Gemessen im Kampf (4×): längstes Bild 80 → 13 ms; in 4K-Menüs 133 → 34 ms. Das Bild bleibt bitgleich.
- **Von ChatGPT, eingebunden (perf-test1/perf-test2):**
  - Smooth-Frames-Schutz bei Überlast.
  - Mailbox-Darstellung mit Fenster-Taktung außerhalb der GPU-Aufrufe.
  - Neue GPU-Wartezeit-Spalten im Leistungsprotokoll.
  - Korrigierter Leistungsbericht.
- **Ebenfalls von ChatGPT:** neue PlayStation-Tastensymbole (Modern). Classic behält die Originalsymbole.
- Das neue Fensterdesign ist in Modern standardmäßig an (`DW2_MODERN_PANELS=0` schaltet es ab).

## Starten (Windows)
1. `DW2-PC-Port-windows-x64.zip` in einen eigenen Ordner entpacken (nicht nach „Programme“).
2. `DW2-PC/dw2.exe` starten.
3. Beim ersten Start dein eigenes Image von **Digimon World 2 (USA)** (`.cue` + `.bin`) wählen.
4. **F1** öffnet die Einstellungen: Sprache, Oberfläche Modern/Classic, Bildformat, Auflösung, Renderer.
5. Für die deutschen Dialoge dein privates `texts.tsv` nach `DW2-PC/Languages/German/` kopieren (nicht enthalten).
