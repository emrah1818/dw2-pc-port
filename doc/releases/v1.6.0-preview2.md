## Starten (Windows)
1. `DW2-PC-Port-windows-x64.zip` in einen eigenen Ordner entpacken (nicht nach „Programme“).
2. `DW2-PC/dw2.exe` starten.
3. Beim ersten Start dein eigenes Image von **Digimon World 2 (USA)** (`.cue` + `.bin`) wählen.
4. **F1** öffnet die Einstellungen: Sprache, Oberfläche Modern/Classic, Bildformat, Auflösung, Renderer.
5. Für die deutschen Dialoge dein privates `texts.tsv` nach `DW2-PC/Languages/German/` kopieren (nicht enthalten).
